# 화면 문구 다듬기

화면 문구가 부자연스럽다는 피드백을 받아 소개 문장과 메뉴·안내 문구를 수정했다. [velog](https://velog.io/)의 짧은 메뉴 이름과 [Notion 사이트](https://www.notion.com/ko/product/sites)의 구체적인 동작 안내를 참고했다. 문장은 서비스 용도에 맞게 새로 작성했다.

| 기존 | 변경 |
|---|---|
| 만들고, 배우고. 다음 가능성을 기록하다. | 프로젝트와 공부 기록, 한곳에 모아보세요. |
| 프로젝트와 공부 기록에서 다음 아이디어를 찾아보세요. | 진행한 프로젝트와 공부한 내용을 정리하고 공유하세요. |
| 오늘의 기록이 내일의 가능성으로. | 프로젝트와 공부 기록을 정리하는 곳 |
| YOUR IDENTITY | 내 정보 |
| BUILD YOUR STORY | 글쓰기 |
| PINNED | 대표 프로젝트 |
| 입력 백업 | 작성 내용 내려받기 |

탐색·공통 헤더/푸터·아카이브·프로필·작성기·카드·상세 컴포넌트의 표시 문구를 수정했다. API, 저장 방식과 공개 범위는 그대로다. 초안과 발행의 차이는 안내에 남겨 잘못된 공개나 저장 혼동을 막는다.

타입 검사와 Git 공백 검사를 통과했다. 운영 배포 결과는 실제 화면 확인 후 보고한다. 티스토리에는 아직 게시하지 않는다.
