## 기능명세서 작성

개발 계획서를 바탕으로 화면별 기능과 저장·공개 규칙을 정리했다. 특히 임시저장과 공개 글 수정을 구분하고, 비공개 기록이 검색·보관함·연결된 기록·사진 주소를 통해 노출되지 않도록 접근 범위를 정의했다.

### 주요 기능 규칙

| 항목 | 정의한 동작 |
|---|---|
| 로그인·프로필 | GitHub 로그인 후 닉네임·개인 주소를 등록한다. 전공·관심 분야·소개는 선택 입력이다. |
| 글 작성 | 프로젝트 / 공부 기록 / 기타를 선택한다. 정식 저장은 제목·유형·본문만 필수이고 안내 항목은 선택이다. |
| 임시저장 | 10초 동안 입력이 없으면 자동저장하고, 수동 저장도 제공한다. 미완성 글은 본인만 볼 수 있다. |
| 공개 글 수정 | 자동저장은 작업 사본에 반영한다. 수정 내용 적용 전까지 기존 공개 내용을 유지한다. |
| 대표 프로젝트 | 본인의 공개 프로젝트 최대 3개를 고정하고 순서를 바꾼다. |
| 보관함 | 다른 사람의 공개 기록을 저장한다. 새로고침·재로그인 후 유지한다. |
| 검색 | 제목·본문·태그로 검색한다. 글 유형과 여러 태그를 함께 적용하며 선택한 태그를 모두 포함한 글을 찾는다. |
| 기록 연결 | 본인의 프로젝트와 공부 기록을 여러 개씩 연결한다. 공개 화면에는 공개된 기록만 표시한다. |
| GitHub 가져오기 | 공개 저장소의 이름·설명·사용 언어·README를 별도 프로젝트 초안으로 가져온다. 이후 자유롭게 수정하며 자동 동기화는 하지 않는다. |
| 사진 | JPG·PNG·WebP, 한 장 5MB 이하, 글당 최대 10장. 비공개 기록의 사진도 본인만 접근한다. |

저장 상태는 저장 중·저장 완료·저장 실패로 구분하고, 실패하면 입력을 유지하도록 정의했다. 또한 각 기능에 저장 후 재조회, 타인 계정 접근 거부, 검색 조건 적용 등의 확인 조건을 작성했다.

현재 단계에서는 기능을 정의했으며, 실제 동작 검증은 구현 후 진행한다.
