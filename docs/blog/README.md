# 블로그 게시 자료

최종 업데이트 대상: https://iamjsy.tistory.com/3

각 개발 단계의 설명·실제 캡처·관련 커밋·검증 결과를 모으는 폴더다. 티스토리 업데이트는 사용자가 마지막에 요청할 때 수행한다. 로컬 초안 작성은 게시 완료를 의미하지 않는다.

| 순서 | 자료 | 상태 |
|---|---|---|
| 01 | 개발 계획서: `../PLAN.md`, 초기 게시 HTML: `../tistory-post.html` | 티스토리 상단 접은 글로 게시됨 |
| 02 | `02-feature-spec.md` | 기능명세서 작성 설명 초안 준비, 아직 게시하지 않음 |
| 03 | `03-backend-profiles.md` | 프로필 백엔드·검증·오류 해결 설명 준비, 아직 게시하지 않음 |
| 04 | `04-supabase-connection.md`, `screenshots/04-supabase-*.png` | 서울 프로젝트 연결·실제 권한 검사·설정 화면 준비, 아직 게시하지 않음 |
| 05 | `05-github-auth.md`, `screenshots/05-*.png` | GitHub 인증·실제 프로필 등록·수정·유지 확인 자료 준비, 아직 게시하지 않음 |

기능명세서 단계에는 실제 애플리케이션 화면이 없으므로 화면 캡처를 만들지 않았다. 이후 구현 화면과 검증은 실제 결과만 추가한다. 각 단계를 동일한 티스토리 글에 이어 붙이고, 필요한 긴 문서 부분은 접은 글로 구성한다.
