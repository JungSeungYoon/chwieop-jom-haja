# 취업좀하자

공대생이 프로젝트와 공부 기록을 쌓고, 자신의 역할과 문제 해결 과정을 보여주는 포트폴리오를 만드는 서비스.

현재 단계: **기획 초안 작성**. 서비스 구현·DB 생성·배포는 아직 진행하지 않았습니다. 사용자와 한 단계씩 방향을 확인한 뒤 진행합니다.

- [서비스 계획서](docs/PLAN.md)
- 개발·통신·보안 등 공학 분야의 학생 대상
- 프로젝트 / 공부 기록 / 기타를 구분한 항목 안내형 작성 + 자유 본문
- 공개·비공개, 대표 프로젝트 핀, 보관함, 검색, 프로젝트–공부 기록 연결
- 배포: Vercel Hobby 검토 / DB·인증·파일 저장: Supabase Free 검토
- 댓글·팔로우·좋아요는 후속 범위

## 진행 순서

기획 확정 → 기능명세서 → 화면 설계 → API 명세서·ERD → 개발 환경 → 단계별 구현·검증 → 무료 배포 → 제출 정리.

이 저장소는 기획 단계이므로 실행할 애플리케이션이 없습니다. 구현 단계에서 실행 방법, `.env.example`, `.gitignore`, 검증 명령을 작성합니다. 비밀 API 키와 사용자 토큰은 커밋하지 않습니다.

개발 과정은 하나의 티스토리 글에 누적 기록할 예정입니다. 실제 작업 단계마다 의미 있는 커밋을 작성하여 과제 요구인 5개 이상을 충족하며, 개수를 맞추기 위한 빈 커밋은 만들지 않습니다.
